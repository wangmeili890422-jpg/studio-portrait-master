CODEX SKILL · VERSION 1.0.0

Studio Portrait Master

亚洲人物单人、合影与儿童照片生成 Skill。默认 4:3、简单背景、完整露头和自然可信的人物状态。

可直接调用 · 支持生图

三步启用

1

确认技能目录

Windows 个人技能目录：

C:\Users\你的用户名\.codex\skills\studio-portrait-master

文件夹内必须包含 SKILL.md。

2

重新加载 Codex

安装后重新打开 Codex，或重启当前应用。新技能没有出现在列表时，优先重启 Codex。

3

在消息中调用

使用 $studio-portrait-master 生成一张中青年夫妻合影。

也可以直接用自然语言描述，系统会自动匹配本 Skill。

支持的五种模式

模式默认表现
中青年单人清爽、亲和、自信；正面或轻微侧身，近景、胸像或自然半身。
中青年合影两位亚洲人物自然靠近、并肩或轻微互动，两张脸都清晰。
中老年单人精神健康、成熟可信；保留自然年龄纹理，头发以深色为主、少量白发。
中老年合影夫妻或亲人温馨陪伴，年龄感协调，不做病弱或过度衰老效果。
儿童人物年龄准确、天真健康、动作和服装符合儿童年龄，不成人化。

统一默认规则

亚洲面孔 4:3 画幅 头部完整露出 简单背景 人物优先 服装可变 季节可变 减少 AI 感
  • 头顶、头发、脸部和下巴尽量完整露出，保留适当头顶空间。
  • 长相、发型、肤色、服装和具体人物不会固定；只有明确说“同一个人”才锁定身份。
  • 默认使用明亮、柔和、健康、可信的商业人物摄影，不主动加入海报文字或广告版式。
  • 以近景、胸像或自然半身为主；只有明确要求时才使用中景、远景或全身。

使用参考图时

请明确说明：只参考人物，不参考文字和版式。
参考这张图中的人物面孔、年龄感、发型和表现方式，不要复制其中的文字、Logo、橙色卡片、图标、海报排版或背景设计。

同事如何使用

  1. 把整个 studio-portrait-master 文件夹复制到同事电脑的个人技能目录：%USERPROFILE%\.codex\skills\。
  2. 重新打开 Codex。
  3. 在新对话输入 $studio-portrait-master，或直接描述人物需求。

如果是团队长期维护，建议把 Skill 放入项目的 .codex/skills/，或进一步打包为团队插件。

常见问题

调用后没有反应？

确认目录名称是 studio-portrait-master，文件名是 SKILL.md，然后重启 Codex。

为什么人物长相每次不同？

这是默认行为。需要保持同一个人时，在请求中加上“保持上一张人物一致”并提供参考图。

为什么不是全身图？

本 Skill 默认人物优先，以近景、胸像和自然半身为主。需要全身时直接写“全身构图”。

能不能生成文字海报？

不属于本 Skill 的范围。本 Skill 只生成干净人物照片，不负责海报文字和排版。
