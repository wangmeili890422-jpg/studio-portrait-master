# 人物模式提示词模板

本文件只在需要组装具体模式的提示词时读取。模板不是固定人脸，也不是固定服装；将方括号字段替换为用户要求，未填写的字段使用 `SKILL.md` 默认值。

## 统一前缀

```text
真实摄影照片，亚洲人物，4:3 画幅，人物优先构图，头部从头顶到下巴完整露出，保留适当头顶空间，简单低干扰背景，人物五官清晰，避免任何文字、Logo、水印、排版和额外人物。
```

## 中青年单人

```text
[年龄]岁的东亚亚洲[男性/女性]，自然清爽的亚洲面孔，[发型与发色]，[服装与季节]，处于[地点/场景]，正面或轻微三分之二侧身看向镜头，表情[自然微笑/自信/温柔/开心]，呈现健康、亲和、可信的人物状态。近景、胸像或自然半身，完整露出头部和下巴，不裁切头顶，不用头发遮挡五官。保留自然毛孔、发丝、眼神光、唇纹和轻微表情不对称，清爽柔和的商业人物摄影。
```

## 中青年双人合影

```text
两位[年龄]岁的东亚亚洲[情侣/夫妻/朋友/同事]，一男一女或按用户指定，处于[地点/季节]，穿着[服装]，并肩、靠肩、轻扶手臂或自然互动，表现健康、开心、幸福和可信的关系。两人的脸都清晰，头顶到下巴完整露出，表情和姿势有细微差异，不做复制粘贴式笑容。4:3、近景或自然半身、简单背景、真实商业生活摄影。
```

## 中老年单人

```text
一位[年龄]岁的东亚亚洲中老年[男性/女性]，精神健康、面容亲切、生活状态稳定，穿着[季节与服装]，处于[地点/场景]，自然看向镜头并带有[温和微笑/自信表情]。保留年龄相符的眼角纹、法令纹、面部轮廓和少量白发；中老年女性以深色或深灰头发为主，只出现零散白发。头部完整露出，4:3、人物优先、干净背景，不病弱、不憔悴、不刻意年轻化。
```

## 中老年双人合影

```text
一对[年龄]岁左右的东亚亚洲中老年[夫妻/伴侣/亲人]，年龄感处于同一生活阶段，穿着[季节与服装]，自然并肩、靠肩、牵手或轻扶肩膀，表现温馨陪伴、健康和幸福。两个人的脸都清晰，头顶和下巴完整露出，女性头发以深色或深灰为主、只有少量白发；保留真实年龄纹理但不做病弱或夸张衰老。4:3、近景或自然半身、简洁背景、明亮柔和的家庭人物摄影。
```

## 儿童

```text
一名[具体年龄]岁的东亚亚洲儿童，穿着符合年龄与季节的[服装]，处于[家庭/校园/公园/室内]，呈现[天真/活泼/安静/好奇]的自然状态。动作、身材、表情和服装符合儿童年龄，头部和脸部完整露出，4:3、人物优先、简单背景、明亮柔和的真实生活摄影。不成人化、不浓妆、不使用成熟姿态，不添加无关人物。
```

## 定向修正模板

```text
保留当前图片的人物身份、年龄、服装、场景、关系和构图，只修改：[明确失败点]。头部完整露出，保持4:3、亚洲人物和简单背景。不要改变其他内容，不增加文字、Logo、水印、额外人物或排版。
```
